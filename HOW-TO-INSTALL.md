# Installing Haykal Structure Lab

Haykal is a web app you can install. No app store is needed, and once installed it works offline.

**App link: https://iimaster12.github.io/haykal-app/**

**Illustrated steps for your device: https://iimaster12.github.io/haykal-app/install.html**

| Device | Browser | How to install |
|---|---|---|
| iPhone or iPad | Safari | Open the link, tap Share, then **Add to Home Screen** |
| Android phone or tablet | Chrome | Open the link and tap **Install app** at the top, or ⋮ → Install app |
| Windows, Mac, Linux, ChromeOS | Chrome or Edge | Open the link and click **Install app** at the top, or the install icon in the address bar |

Haykal then gets its own icon, opens full screen, and keeps working offline after the first visit.

## No internet at all?

Download `Haykal-offline.html` from the [latest release](https://github.com/iimaster12/haykal-app/releases/latest), copy it to a laptop or USB stick, and double-click it. It runs in the browser on Windows, Mac, Linux and ChromeOS with no internet and no server. iPhones and iPads do not run local web files, so use the install link above on those.

## App stores

The same app can be packaged for Google Play and the Microsoft Store with https://www.pwabuilder.com using the app link. The Apple App Store needs a Mac with Xcode and a paid Apple Developer account; on iPhone, Add to Home Screen gives the same app without it.

# تثبيت «هيكل»

«هيكل» تطبيق ويب يمكن تثبيته، دون الحاجة إلى متجر تطبيقات، ويعمل دون إنترنت بعد التثبيت.

**رابط التطبيق: https://iimaster12.github.io/haykal-app/**

**خطوات مصوّرة لجهازك: https://iimaster12.github.io/haykal-app/install.html**

| الجهاز | المتصفح | طريقة التثبيت |
|---|---|---|
| آيفون أو آيباد | Safari | افتح الرابط، ثم زر المشاركة، ثم **إضافة إلى الشاشة الرئيسية** |
| هاتف أو جهاز لوحي أندرويد | Chrome | افتح الرابط واضغط **تثبيت التطبيق** في الأعلى، أو ⋮ ← تثبيت التطبيق |
| ويندوز وماك ولينكس وكروم أو إس | Chrome أو Edge | افتح الرابط واضغط **تثبيت التطبيق** في الأعلى، أو أيقونة التثبيت في شريط العنوان |

بعد ذلك يظهر «هيكل» بأيقونته الخاصة، ويفتح بملء الشاشة، ويعمل دون إنترنت بعد أول فتح.

## لا يوجد إنترنت إطلاقًا؟

حمّل `Haykal-offline.html` من [آخر إصدار](https://github.com/iimaster12/haykal-app/releases/latest)، وانسخه إلى الحاسوب أو ذاكرة USB، ثم افتحه بنقرتين. يعمل في المتصفح على ويندوز وماك ولينكس وكروم أو إس دون إنترنت ودون خادم. أجهزة آيفون وآيباد لا تشغّل ملفات الويب المحلية، لذلك استخدم رابط التثبيت أعلاه عليها.
